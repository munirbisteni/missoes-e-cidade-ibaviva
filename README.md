# Missões e Cidade · IBAVIVA

Site voluntário que apresenta os missionários e os projetos sociais apoiados pela igreja IBAVIVA, feito para acompanhar um ciclo de pregações sobre missões.

**No ar:** https://missoes-e-cidade-ibaviva.vercel.app

## O que eu fiz

Fiz sozinho, de ponta a ponta, em uma semana e sem custo de infraestrutura: design, desenvolvimento, publicação e revisões depois da entrega.

## O que o site tem

- **Abertura com globo 3D** animado, com nuvens em volta (react-globe.gl + Three.js).
- **Projetos sociais** (Arca e outros) em carrossel de fotos, com formas de colaborar.
- **Missionários** em ordem alfabética, com modal de detalhes e galeria de fotos.
- Versões para celular e computador, com abertura em tela cheia.
- Imagens em WebP para carregar rápido em rede móvel.
- Métricas de acesso com Vercel Analytics.

## Tecnologias

React 19 · Vite · Tailwind CSS 4 · Swiper · react-globe.gl · Vercel

## Como rodar

```bash
npm install
npm run dev
```
